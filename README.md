# 부스패스

가고 싶은 부스를 직접 고르거나 관심 분야와 부스 수로 추천받아 관람 순서를 계획하는 웹입니다. 서울 코믹월드, 일러스타 페스, 커피 박람회를 소재로 한 샘플 데이터를 제공합니다.

## 실행

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
cd web
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 다른 포트가 필요하면 `BOOTHPATH_PORT=4174 npm run dev`로 실행합니다.

```sh
npm test       # 경로 계산과 추천 엔진 검증
npm run build # dist/에 정적 파일 생성
```

## 동작

- 부스 직접 선택 또는 인기도·특별함·관심 분야에 따른 추천
- 전시장 통로를 따라 계산하는 이동 경로와 방문 순서
- 입구 또는 현재 부스를 출발점으로 선택하고, 필요하면 출발점으로 돌아오는 경로 계산
- 방문 완료 표시 후 마지막으로 완료한 부스에서 남은 부스만 다시 계획
- 브라우저에 계획 자동 저장 및 링크로 행사·출발점·부스 선택 공유

부스 사이 이동은 통로 그래프의 최단 경로를 사용합니다. 방문할 부스가 10개 이하이면 동적 계획법으로 최단 방문 순서를 계산합니다. 10개를 초과하면 첫 부스를 달리한 최근접 이웃 탐색과 2-opt 개선으로 이동 거리를 줄이며, 전역 최적 경로를 보장하지 않습니다. 추천은 인기도 우선, 특별함 우선, 두 기준과 분야 다양성을 반영한 균형형 중에서 고를 수 있습니다.

현재 위치는 출발점 목록에서 직접 지정합니다. 방문 완료를 표시한 순서의 마지막 부스가 남은 동선을 다시 계산할 때의 출발점이 됩니다. 공유 링크를 열면 방문 완료 기록은 초기화됩니다. 비공개 배포 페이지의 링크를 받은 사람은 해당 페이지 접근 권한도 필요합니다.

## 데이터 범위

부스 이름, 전시장 배치, 인기도, 특별함 점수는 기능 체험용 가상 데이터입니다. 실제 행사 부스 목록, 실시간 대기 시간, GPS와 연결되어 있지 않습니다. 이동 거리와 예상 시간도 샘플 배치를 바탕으로 한 추정값입니다. 실제 행사에 적용하려면 `data.js`의 부스·통로·입구 데이터를 해당 전시장에 맞게 교체해야 합니다.

`app.js`는 화면과 상태, `data.js`는 행사 데이터, `engine.js`는 추천 및 경로 계산을 담당합니다. 배포는 정적 호스팅으로 가능하며 별도 백엔드는 필요하지 않습니다.
